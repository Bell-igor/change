# СМЕНА — цифровой инструмент привлечения молодых специалистов в «Очаково»

Решение кейса «Очаково» на хакатоне **«Открой Моспром»** (23–25 октября 2026).
Концепция **A + C + B**: игровой путь в формате мини-аппа ВК + «Лаборатория вкуса» + наставник с пре-бордингом.

## Как открыть (30 секунд)

1. Открыть файл **`index.html`** двойным щелчком (Chrome, Edge, Safari, любой современный браузер).
2. Ничего устанавливать не нужно: всё работает офлайн, без сервера и без интернета.
3. Рекомендуется смотреть в мобильном окне: `F12 → Toggle device toolbar → iPhone 12`. На десктопе интерфейс сам ограничен шириной 480 px.

**Демо-режим с заполненным прогрессом** (удобно для показа жюри):

| Ссылка | Что покажет |
|---|---|
| `index.html?demo=1` | сразу финальный экран игрока |
| `index.html?demo=1#s-flavor` | «Лаборатория вкуса» с готовым вкусом |
| `index.html?demo=1#s-hr` | «Пульт HR» с воронкой и заявками |
| `index.html?demo=1#s-board` | рейтинг вузов |
| `index.html?demo=1#s-mentor` | чек-лист наставника |
| `index.html#s-track` | любой экран по якорю (`s-splash`, `s-history`, `s-line`, `s-quality`, `s-quiz`, `s-form`) |
| `index.html?selftest=1` | автотест всей воронки: проходит игру за вас и печатает отчёт `SELFTEST PASS/FAIL` |

Обычный запуск — просто `index.html`: чистый старт для нового пользователя.

## Сценарий демонстрации (3 минуты)

1. **Сплэш** → «Пройти первую смену».
2. **Выбор трека**: инженер / технолог-лаборант / оператор-склад. Показывает три блока, которые нужны компании.
3. **Смена 1, история**: сопоставить год и событие (1978, 1994, 1995, 1998) → факты о компании.
4. **Смена 2, пульт линии**: найти станцию вне регламента (давление CO₂ 3,4 бар при норме 2,0–2,6).
5. **Смена 3, лаборатория**: забраковать партию №215 (кислотность 3,6 при норме до 3,0).
6. **Смена 4, лаборатория вкуса**: выбрать основу + 3 ингредиента → получить личный вкус, профиль и карточку для соцсетей (скачивание PNG).
7. **Смена 5, квиз**: 5 контрольных вопросов о компании — обязательный блок из требований кейса.
8. **Смена 6, итоги**: ранг, баллы, призы (экскурсия, мерч, собеседование).
9. **Заявка**: ФИО, телефон, дата рождения с проверкой **18+**, вуз, курс, вакансия, готовность выйти, согласие на обработку данных.
10. **«Пульт HR»** (`#s-hr`): воронка, стоимость заявки, список заявок, выгрузка JSON.

## Что реализовано и как это закрывает требования кейса

| Требование кейса | Где в решении |
|---|---|
| Работающий прототип цифрового инструмента | мини-апп «Смена» (веб-прототип под ВК Мини-апп), 13 экранов, 5 игровых механик |
| Сбор данных кандидата: ФИО, контакты, дата рождения, вакансия, готовность выйти, вуз/колледж | экран «Заявка», валидация 18+, запись в `localStorage`, экспорт JSON |
| Лёгкая игровая форма подачи | смены по 40–90 секунд, баллы, прогресс, рейтинг |
| Контакт с целевой аудиторией | после заявки — «Наставник»: чек-лист пре-бординга, напоминания в VK/TG |
| Контрольные вопросы на знание компании | «Смена 5» — 5 вопросов с разбором ответов |
| История компании, направления, карьерные возможности, бренды | смена 1 (факты), треки (направления и зарплаты), смена 4 (создание вкуса), финал (карьерные шаги) |
| Концепция HR-бренда | слоган «Твой первый вкус», ранг «Мастер смены», визуальный язык брендбука |
| Масштаб внедрения: головной офис | веб + ВК-мини-апп, без установки приложения |
| Аналитика | «Пульт HR»: воронка, CPL, конверсии, распределение по трекам |

Видео о профессиях из материалов кейса (`Химик-лаборант`, `Оператор линии розлива`,
`Машинист оборудования`, `Процесс создания нового вкуса`) не входят в архив —
они используются в концепции ролика и встраиваются в смену «один день из жизни» на этапе продакшена.

Данные хранятся в браузере: ключи `och_smena_v1` (прогресс), `och_leads_v1` (заявки), `och_checklist_v1` (чек-лист).
Кнопка «Сбросить демо-данные» — в «Пульте HR».

## Что нужно для продакшена (ВК Мини-апп)

1. **Фронтенд**: этот же код → VK Bridge (`VKWebAppInit`, `VKWebAppGetUserInfo`), подпись и шаринг через `VKWebAppShare`, сторис — `VKWebAppShowStoryBox`.
2. **Бэкенд**: приём заявок → Битрикс24/HRM (вебхук), хранение прогресса, антифрод, лимиты.
3. **Контент**: реальные фото/видео цехов вместо текстовых смен, обновление вакансий и зарплат из HR-системы.
4. **Юридическое**: согласие на обработку ПД по 152-ФЗ, политика, модерация ВК, возрастной фильтр 18+.
5. **Аналитика**: события воронки (старт, смена, квиз, заявка) + UTM/QR по каналам, дашборд в «Пульте HR».
6. **Пилот**: 6 недель, 3 вуза-партнёра, QR в общежитии и на экскурсиях, замер CPL и доли дошедших до заявки.

## Ограничения прототипа

- Данные демонстрационные: заявки не уходят в CRM, а сохраняются локально.
- Видео и фото — из материалов кейса; в прототипе не встроены в плеер (задел на смену «один день из жизни»).
- Рейтинг вузов — статичная демонстрация механики.
- Маскот и мерч — концепция, требует согласования с бренд-отделом «Очаково» (по условиям кейса).
