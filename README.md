# СМЕНА — прототип мини-приложения для «Очаково»

Игровой путь кандидата: 6 смен на производстве → своя профессия и свой вкус → заявка на практику → наставник.
Решение кейса «Очаково» на хакатоне «Открой Моспром» (23–25 октября 2026).

## Открыть и попробовать

**Онлайн:** https://bell-igor.github.io/change/

Локально: скачать папку и открыть `index.html` двойным щелчком — всё работает офлайн, без сборки и зависимостей.

| Ссылка | Что покажет |
|---|---|
| `?demo=1` | сразу финал игрока |
| `?demo=1#s-flavor` | «Лаборатория вкуса» с готовым вкусом |
| `?demo=1#s-hr` | пульт HR: воронка, стоимость заявки, живые заявки |
| `?demo=1#s-board` | рейтинг вузов |
| `?demo=1#s-mentor` | чек-лист наставника (пре-бординг) |
| `?selftest=1` | автотест: проходит всю воронку и печатает `SELFTEST PASS/FAIL` |

## Палитра

Тёмная тема на фирменных цветах брендбука «Очаково»:

| Роль | Цвет |
|---|---|
| Основной (герой, кнопки, графики) | синий `#0086D6` (Pantone 2194) |
| Тёмный вариант синего, градиент героя | `#0A3555` |
| Акцент и подписи на тёмном | `#4FB2EA` / `#6FC4F2` |
| Поверхности | графит `#0F1418`, `#1A2126`, `#212A30` |
| Текст | `#F1F4F6` / `#BAC4C9` / `#88959C` |
| Ошибки | красный `#D50032` (только валидация и неверные ответы) |

Все цвета — CSS-переменные в начале `styles.css`, карточка вкуса на canvas берёт их же,
поэтому скачанная картинка совпадает с интерфейсом. Лайм и тёмно-зелёный из брендбука
в интерфейс не попали: они остались в исходной палитре вариантов.

## Что посмотреть за 3 минуты

1. **Знакомство (шаг 1)** — имя, телефон, дата рождения с проверкой 18+ и согласие. Контакты берём сразу:
   HR видит черновик, даже если человек не дошёл до финала.
2. **Выбор трека** — инженер / технолог-лаборант / оператор-склад.
3. **Смена 1** — история компании: сопоставить годы и события (1978, 1994, 1995, 1998).
4. **Смена 2** — пульт линии розлива: найти станцию вне регламента.
5. **Смена 3** — лаборатория: забраковать партию с нарушением кислотности.
6. **Смена 4** — «Лаборатория вкуса»: собрать свой вкус и скачать карточку для соцсетей.
7. **Смена 5** — контрольный квиз о компании.
8. **Смена 6** — итоги, ранг, призы.
9. **Заявка (шаг 3)** — контакты уже собраны (карточка с «изменить»), остаётся вуз, курс, вакансия и готовность выйти.
10. **Пульт HR** — воронка, метрики, заявки и незавершённые черновики с прогрессом по сменам.

## Технически

- Чистый HTML/CSS/JS без сборки, зависимостей и интернета.
- Mobile-first: ширина контента ограничена 480 px.
- Данные прототипа — в `localStorage` (ключи `och_smena_v1`, `och_leads_v1`, `och_checklist_v1`).
- Демо-режимы (`?demo=1`, `?selftest=1`) нужны для показа и проверки, в продакшене отключаются.
- Публикация: GitHub Pages, автодеплой из `main` через `.github/workflows/pages.yml`.

## Ограничения

Прототип демонстрационный: заявки не уходят в CRM, а сохраняются в браузере; рейтинг вузов — демонстрация механики.
